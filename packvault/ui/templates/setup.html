What initialization does

  • Creates PostgreSQL schema (tables are not created on ordinary startup)
  • Records initialization metadata in system_state
  • Imports {{ token_count }} Maven token definition(s) from current configuration (hashes only)
  • Seeds default RBAC groups (publishers, readers)
  • Stores the encryption key fingerprint when encryption is enabled

The bootstrap admin password stays in environment configuration only — it is never stored in PostgreSQL.
